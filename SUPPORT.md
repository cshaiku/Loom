# Support

Use GitHub issues for public bugs, feature requests, documentation defects, and
packaging feedback.

Do not use public issues for suspected vulnerabilities. Follow
[SECURITY.md](SECURITY.md).

## Useful Details

Include:

- Loom version from `loom version`;
- operating system and shell;
- command arguments;
- small repro input, if shareable;
- expected behavior;
- actual behavior;
- output from `loom status --json` or `loom verify --json` when relevant.

## Current Product State

`0.22.x` is an analyzer and transfer-planning line. The `v1.0.0` target is a
